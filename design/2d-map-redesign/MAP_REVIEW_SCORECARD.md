# Sound Village 2D 맵 리디자인 — 맵 검수 스코어카드

작성일: 2026-08-28  
용도: 월드맵 및 여섯 마을의 시안·구현·이벤트 버전을 동일한 기준으로 평가

DB canonical key, unique constraint, RPC, migration, annotation 수정·legacy 처리·보상 재시도는 `SCOPE_AND_CONTEXT_FREEZE.md`에 따라 향후 기술 안정화 제안이며 **시각 whitebox의 합격 게이트가 아니다**.

## 1. 사용 원칙

이 점수표는 예쁜 맵을 고르는 인기 투표가 아니다. 연구 흐름, 목표 가독성, 이동 안전성, 여섯 마을의 참여 균형을 관찰 가능한 기준으로 검수한다.

- 각 항목을 1~5점으로 평가한다.
- 표의 1·3·5점 기준 사이에 해당하면 2점 또는 4점을 준다.
- 추측으로 점수를 채우지 않고 화면 캡처, 플레이 기록, 측정값 또는 이슈 링크를 근거란에 남긴다.
- “해당 없음”은 허용하지 않는다. 적용되지 않아 보이는 항목도 그 이유와 대체 검증을 기록한다.
- 연구 안전성 게이트는 가중 총점보다 우선한다.

활성 sound 3~7개, 공간 밀도 20/50/30%, 접근 시간 편차 ±15%, 마을 매력도 차이 0.75, 보상 연출 0.8~1.5초, 3초 인식 테스트 기준은 **1차 휴리스틱이자 파일럿 검수 후 조정 가능한 디자인 목표**다. 아직 연구적으로 검증된 절대 임계값이 아니며, 조정할 때는 파일럿 근거와 점수표 버전을 기록한다.

## 3. 연구 안전성 게이트

다음 항목 중 하나라도 “아니오”면 점수와 관계없이 **반려**한다.

| 게이트 | 예/아니오 | 근거 |

## 5. 점수 판정

### 승인

- 모든 연구 안전성 게이트가 “예”다.
- 가중 총점이 80점 이상이다.
- 핵심 항목 1, 2, 7, 8, 14, 15가 각각 4점 이상이다.
- 어떤 항목도 2점 이하다.

### 조건부 수정

- 게이트 위반은 없고 총점 70~79점이거나 비핵심 항목에 2점이 있다.
- 수정 항목, 담당, 재검수 날짜를 기록하고 같은 환경에서 다시 평가한다.

### 반려

- 연구 안전성 게이트 하나 이상 실패
- 총점 70점 미만
- 핵심 항목 중 하나가 3점 이하
- 접근 불가능한 활성 sound, 데이터 흐름 회귀, sound 의미 프라이밍이 발견됨

## 6. 측정 방법

### 6.1 3초 목표 인식 테스트

1. 이동 전 대표 화면을 3초만 보여준다.
2. 화면을 가린 뒤 “어디로 이동해야 하는가”, “가장 가까운 상호작용 대상은 무엇인가”, “출구는 어디인가”를 묻는다.
3. 5명 이상 평가자의 정답 위치와 확신도를 기록한다.
4. 제작자가 설명한 뒤 재평가한 결과는 승인 근거로 쓰지 않는다.

### 6.2 이동·충돌 테스트

- 입구→첫 활성 sound와 연속 활성 sound 5개까지의 시간을 잰다.
- 키를 놓지 않은 연속 이동과 세밀한 모서리 이동을 각각 시험한다.
- 각 sound에 최소 두 방향에서 접근한다.
- 막힘, 되돌아감, 오클릭, 충돌 경계 오인의 수를 기록한다.
- 마을 간 시간 비교에는 같은 이동 속도와 같은 입력 장치를 쓴다.

### 6.3 밀도 테스트

- 주요 경로를 따라 카메라 한 화면 단위로 캡처한다.
- 활성 sound, 움직이는 장식, 강한 발광 오브젝트를 각각 센다.
- 3~7 범위를 벗어난 화면의 이유와 수정안을 남긴다.
- 단순히 marker를 숨겨 수를 맞추지 말고 진행 상태와 실제 접근 가능성을 함께 확인한다.

### 6.4 마을 매력 균형 테스트

- 마을 이름과 보상량을 가리고 같은 크기의 대표 화면을 무작위 순서로 제시한다.
- “가고 싶은 정도”, “완성도”, “시각적 보상성”을 각각 1~5점으로 받는다.
- 항목별 마을 평균의 최대-최소 차이를 계산한다.
- 한 마을이 반복해 높으면 보상을 줄이는 대신 채도, 효과 수, 랜드마크 규모, 화면 밀도를 조정한다.

### 6.5 annotation 품질 위험 점검

- marker 주변 오브젝트가 sound의 원천·감정·행동 표현을 암시하는지 두 명 이상이 독립 검토한다.
- annotation 패널을 연 상태에서 입자·광원·NPC·보상 애니메이션의 움직임과 가림을 녹화한다.
- 리디자인 전후 재생 횟수, listening time, 표현 길이, technical failure, 미완료 복귀와 이탈률을 비교한다.
- 차이가 발견되면 시각 효과만 원인이라고 단정하지 않고 연구 조건을 함께 검토한다.
