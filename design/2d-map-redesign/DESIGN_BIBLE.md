# Sound Village 2D 맵 리디자인 — 공통 디자인 바이블

작성일: 2026-08-28  
적용 범위: 월드맵과 Animal, Human, Nature, Urban, Music, Lab 여섯 마을  
기준 자료: `BASELINE_AUDIT.md`, `baseline/`의 7개 기준 화면, `design/concepts/lab-sound-observatory-concept-v1.png`

범위와 구현 상태의 분류는 `SCOPE_AND_CONTEXT_FREEZE.md`를 따른다. DB canonical key·unique constraint·RPC·migration·수정 및 재시도 정책은 이 디자인 바이블의 불변 조건이 아니라 향후 기술 안정화 제안이다.

## 1. 디자인 명제

Sound Village의 맵은 “탐험할 수 있는 연구 인터페이스”다. 플레이어는 세계를 구경하는 동시에 현재 해야 할 행동을 즉시 이해해야 한다. 모든 시각 결정은 다음 우선순위를 따른다.

1. 연구 프로토콜과 annotation 품질
2. 활성 소리 발견과 안전한 이동
3. 여섯 마을 간 참여 균형
4. 마을 정체성과 정서적 몰입
5. 장식의 풍부함과 이벤트성

핵심 스타일은 **hand-painted 환경 + pixel-art 캐릭터·상호작용 아이콘**의 하이브리드다. 배경은 따뜻하고 회화적일 수 있지만, 플레이 가능한 경계와 연구 인터랙션은 픽셀 단위로 선명해야 한다.

- 시점은 정사영에 가까운 탑다운 3/4로 통일한다. 건물의 정면은 보이되 원근 수렴으로 타일 좌표가 왜곡되지 않아야 한다.
- 분위기는 cozy를 지향하지만 현재 annotation 목표가 장식에 묻히지 않게 한다.
- 상용 2D 게임 수준의 공간 계층은 디테일 양이 아니라 큰 실루엣, 읽히는 동선, 일관된 재료와 완성도에서 만든다.
- 생성 이미지와 기존 pixel asset을 함께 쓸 때 최종 표시 배율은 정수 배율을 우선하고, 캐릭터 주변에 반픽셀·혼합 해상도 edge가 남지 않게 한다.

## 2. 공통 시각 원칙

### 2.1 레이어 순서

맵은 아래 순서로 읽혀야 한다.

1. 지형·바닥: 걷는 곳과 걷지 못하는 곳을 구분
2. 주요 경로: 입구, 중앙 허브, 주요 시설 연결
3. 건물·랜드마크: 마을 정체성과 방향 기준점
4. 생활 소품·식생: 중간 밀도의 이야기 전달
5. 소리 발견 지점: 모든 장식보다 높은 상호작용 우선순위
6. 캐릭터와 UI: 전경 장식에 가리지 않는 최상위 기능 레이어

회화적 빛과 그림자는 길의 외곽을 부드럽게 만들 수 있지만 통행 가능 영역의 실제 경계를 속이면 안 된다. 충돌 경계와 그림의 경계 차이는 최대 0.5타일을 목표로 한다.

### 2.2 공통 렌더링 언어

- 기본 타일 격자는 유지하되 반복 패턴은 3~5종 변형으로 숨긴다.
- 건물과 자연물은 큰 실루엣을 먼저 구분하고 내부 디테일은 확대 화면에서만 보강한다.
- outline은 배경 오브젝트보다 캐릭터·상호작용 오브젝트에 1단계 더 강하게 쓴다.
- 빛나는 효과는 활성 소리, 저장 성공, 실제 상호작용 가능 상태에 한정한다.
- 그림자는 광원 방향을 한 마을 안에서 통일하고, 캐릭터 발 위치와 충돌 지점을 가리지 않는다.
- emoji는 제작 중 임시 fallback에만 허용하며 승인 이미지에는 사용하지 않는다.

### 2.3 기능적 시각 계층

| 순위 | 대상 | 명도·채도 | 발광·움직임 |
|---:|---|---|---|
| 1 | 현재 목표와 대표 랜드마크 | 목표는 주변보다 명도 대비가 가장 높고, 랜드마크는 큰 실루엣으로 읽되 채도는 목표보다 낮음 | 목표에만 느린 맥동 허용. 랜드마크 애니메이션은 낮은 빈도 |
| 2 | 길, 입구, 상호작용 가능한 소리 | 길은 연속 명도 띠, 입구는 외곽 대비, 소리는 제한된 강조색 | sound marker에 공통 호흡형 발광. 길 자체는 점멸 금지 |
| 3 | 분위기 장식 | 중·저채도와 좁은 명도 범위 | 움직임은 화면당 권장 수 안에서 느리고 비동기적으로 사용 |

대표 랜드마크는 공간 방향을 설명하는 1순위이지만, 순간 과업인 활성 sound의 국소 대비를 빼앗아서는 안 된다. 보상 팝업은 저장 성공 뒤 일시적으로만 1순위가 된다.

## 3. 공간 규격

### 3.1 고정 기준

| 항목 | 기준 |
|---|---:|
| 마을 맵 | 48 × 36 타일 |
| 타일 크기 | 32 px |
| 마을 전체 캔버스 | 1536 × 1152 px |
| 현재 마을 카메라 기준 | 24 × 18 타일 |
| 월드맵 | 120 × 90 타일 |
| 현재 월드 카메라 기준 | 30 × 22 타일 |

화면 비율이나 모바일 대응 때문에 렌더 크기를 조정할 수는 있지만 논리 타일, 좌표, 충돌 판정과 sound 배치를 시각 작업만으로 바꾸지 않는다.

### 3.2 경로와 상호작용 여백

| 공간 | 목표 규격 | 실패 조건 |
|---|---|---|
| 주 경로 | 기본 3타일(96px), 허브·입구 4~5타일 | 장식·NPC 때문에 유효 폭이 2타일 미만 |
| 보조 경로 | 기본 2타일(64px) | 한 타일 병목이 연속 3타일 이상 |
| 건물 입구 접근 | 문 앞 3×3타일의 시야·접근 영역 | 문이 전경·효과에 가리거나 한 방향에서만 접근 가능 |
| 활성 소리 접근 | 중심 주변 최소 1타일 비움, 주 접근 방향 2타일 확보 | 충돌체가 상호작용 반경을 침범 |
| 중앙 허브 | 최소 6×6타일의 읽을 수 있는 열린 영역 | 랜드마크가 플레이어·아이콘을 지속 가림 |
| 맵 출입구 | 화면 진입 후 3초 안에 주 경로와 함께 식별 *(provisional)* | 출구·장식·잠긴 문이 같은 형태 |

캐릭터의 시각 스프라이트 크기와 충돌 footprint를 동일시하지 않는다. 현재 캐릭터는 타일보다 크게 보일 수 있으므로 발 아래 접점과 그림자로 논리 위치를 표시하고, 머리·장식 부분은 충돌 판정 근거로 사용하지 않는다.

### 3.3 건물·랜드마크 비례

- 주요 랜드마크: 마을당 1개. 권장 폭 8~12타일, 높이 6~9타일.
- 보조 랜드마크: 마을당 2~4개. 주요 랜드마크 실루엣 면적의 30~60%.
- 일반 건물: 주요 랜드마크보다 채도·명암 대비·애니메이션을 낮춘다.
- 화면 안에서 주요 랜드마크와 활성 소리가 겹치면 활성 소리가 위계상 우선한다.
- 건물의 보이는 문 위치와 실제 진입 좌표를 일치시킨다.

## 4. 밀도와 가독성

이 문서의 활성 sound 3~7개, 공간 밀도 20/50/30%, 접근 시간 편차 ±15%, 마을 매력도 차이 0.75, 보상 연출 0.8~1.5초, 3초 인식 테스트 기준은 아직 연구적으로 검증된 임계값이 아니다. 모두 **1차 휴리스틱이자 파일럿 검수 후 조정 가능한 디자인 목표**이며, 변경 시 파일럿 근거와 버전을 기록한다. 연구 프로토콜의 불변 조건으로 취급하지 않는다.

### 4.1 공간 밀도 목표

각 마을 전체 면적을 체감 밀도로 분류한다.

- 고밀도 이야기 구역: 20% *(provisional)*
- 중밀도 생활 구역: 50% *(provisional)*
- 휴식·이동 여백: 30% *(provisional)*
- 허용 오차: 각 항목 ±5%p

고밀도 구역은 랜드마크 주변에 집중하고 주 경로 전체를 장식으로 채우지 않는다. 빈 공간은 미완성이 아니라 시선 회복과 이동 예측을 위한 기능 영역이다.

### 4.2 한 화면 장식·상호작용 상한

24×18타일 카메라 기준:

- 동시에 보이는 **활성 소리 지점 목표 3~7개** *(provisional)*, 경고 8개, 실패 10개 이상
- 서로 독립적으로 움직이는 환경 애니메이션 목표 0~4개, 최대 6개
- 강한 발광·맥동 오브젝트는 활성 소리 포함 최대 5개
- 같은 종류 소품의 연속 반복은 5개 이내에서 형태·방향·명도를 변형
- 비활성·미해금 sound marker는 활성 marker와 같은 발광을 사용하지 않음

현재 Animal, Nature, Music 기준 화면은 여러 활성 marker가 한꺼번에 보여 기능적 위계가 약해질 위험이 있다. 후속 맵 단계에서는 marker 수를 임의 삭제하지 말고 카메라별 분산, 상태별 표시, 배경 효과 절제를 통해 해결한다.

### 4.3 3초·흑백·축소 테스트

모든 맵 화면은 다음 테스트를 통과해야 한다.

- 3초 노출: 최소 5명의 검수자 중 4명 이상이 주요 경로, 입구/출구, 가장 가까운 활성 소리를 지목한다. *(provisional)*
- 흑백: 색을 제거해도 길과 비통행 영역, 활성/비활성 상태가 명도·형태로 구분된다.
- 320×180 축소: 주요 랜드마크, 플레이어, 활성 소리의 실루엣이 뭉개지지 않는다.
- 모바일 실제 크기: 상호작용 아이콘과 텍스트가 서로 겹치지 않고 터치 목표가 최소 44 CSS px를 확보한다.

## 5. 소리 발견 지점 공통 체계

소리 발견 지점은 마을마다 장식 형태가 달라도 상태 문법은 같아야 한다.

### 5.1 상태 문법

| 상태 | 공통 표현 | 금지 표현 |
|---|---|---|
| 사용 가능 | 뚜렷한 외곽 링 + 낮은 속도의 호흡형 맥동 + 상호작용 아이콘 | 정답 원천을 보여주는 구체적 그림 |
| 접근 중 | 링 대비 상승, 방향 힌트 1개 | 화면 전체 플래시 |
| 상호작용 범위 | 짧은 테두리 수축, 키/터치 라벨 | 재화 아이콘과 동일한 형태 |
| 완료 | 맥동 제거, 체크/채움 형태, 채도 감소 | 활성 상태와 같은 발광 |
| 잠김/다음 블록 | 낮은 대비의 봉인 형태, 조건 라벨 | 활성 상태처럼 반짝임 |
| technical audio error | 경고 외곽선 + 재시도/맵 복귀 라벨 | 완료·재화·annotation 상태로 표현 |

형태는 최소 세 요소로 구분한다: 외곽 실루엣, 내부 glyph, 짧은 텍스트 라벨. 색 하나만으로 상태를 전달하지 않는다.

### 5.2 마을별 외피

공통 링과 상태 glyph는 유지하고 외곽 받침·입자만 마을 정체성에 맞춘다. 예: Animal의 둥근 목재 받침, Urban의 각진 신호 패널. 외피 차이는 상호작용 가능 여부보다 먼저 눈에 띄면 안 된다.

### 5.3 발견→annotation→보상 순서

1. 플레이어가 marker에 접근한다.
2. 상호작용 라벨이 나타난다.
3. annotation 패널이 열리고 환경 효과는 감쇠한다.
4. 오디오 재생과 표현 입력이 완료된다.
5. 저장 성공 뒤 marker가 완료 상태로 바뀐다.
6. 재화/재료 보상은 0.8~1.5초의 짧은 연출로 표시한다. *(provisional)*

보상 연출은 패널 입력란·재생 컨트롤을 가리지 않으며, 저장 전에는 재화를 예고하는 과한 애니메이션을 보이지 않는다.

voluntary skip 상태와 UI는 만들지 않는다. 패널 닫기는 저장 없는 미완료 복귀이며, technical failure는 재시도·맵 복귀·연구자 문의를 제공하는 별도 오류 상태다. 중복 방지를 위한 canonical key·DB 제약·멱등 저장 방식은 향후 기술 안정화 제안이며 이번 whitebox의 승인 조건이 아니다.

## 6. 재화 시각 체계 제안

아래는 **디자인 제안**이며 현재 코드에 구현된 기능이 아니다. 실제 명칭·경제·schema는 연구자와 제품 책임자의 별도 승인이 필요하다.

| 마을 | 제안 재료명 | 실루엣 | 주색 / 보조색 | 촉감·패턴 |
|---|---|---|---|---|
| Animal | 온기 방울 | 둥근 방울·발자국 홈 | `#D98C45` / `#FFF0C2` | 부드러운 목재·털결 |
| Human | 이야기 실타래 | 감긴 타원·매듭 | `#C85C78` / `#FFD6BE` | 직물·교차 실선 |
| Nature | 이슬 결정 | 잎을 품은 물방울 | `#3F9F83` / `#CDEB88` | 투명 결정·잎맥 |
| Urban | 신호 합금 | 육각 너트·파형 홈 | `#4F6F91` / `#F2C14E` | 금속·점선 회로 |
| Music | 공명 조각 | 비대칭 음파 판 | `#7C5CC4` / `#F0C8FF` | 반투명 레코드 홈 |
| Lab | 스펙트럼 프리즘 | 절단된 삼각 결정 | `#245B86` / `#E2B44D` | 유리·분광선 |

규칙:

- 16px, 24px, 32px 크기에서 실루엣만으로 6종을 구분한다.
- 명칭의 첫 글자 또는 zone 라벨을 tooltip과 획득 내역에 함께 표시한다.
- 집꾸미기 recipe UI는 필요한 재료를 나열하고 부족한 마을을 강조하되 특정 마을로 자동 유도하지 않는다.
- 인기 아이템 recipe의 마을별 요구 빈도와 총량을 균등화한다.
- 소리 marker와 재화 아이콘은 외곽 형태, 맥동, 사용 위치를 공유하지 않는다.

## 7. 여섯 마을 정체성

### 7.1 Animal — 함께 사는 생명의 온기

- 콘셉트: 목초지와 작은 돌봄 시설이 연결된 생활형 생태 마을
- 감정: 따뜻함, 호기심, 돌봄
- 주요 랜드마크: 둥근 지붕의 공동 돌봄 헛간
- 보조 공간: 연못 관찰대, 작은 방목장, 먹이 저장소
- 팔레트: 풀 `#6F9E52`, 흙 `#B98555`, 크림 `#F2E3BA`, 강조 `#D98C45`
- 실루엣: 낮고 둥근 지붕, 목책의 완만한 곡선
- 피할 것: 특정 sound marker 옆에 해당 동물을 직접 배치해 정답을 암시하는 구성, 과도한 울타리 미로
- 이동 균형: 울타리는 시선 유도에 쓰되 주 경로에 막다른 골목을 만들지 않는다.

### 7.2 Human — 관계와 일상의 광장

- 콘셉트: 사람의 생활 흔적이 모이는 공동체 광장과 골목
- 감정: 친밀함, 활기, 안도감
- 주요 랜드마크: 공동 회관과 열린 계단 광장
- 보조 공간: 찻집 테라스, 우편·이야기 게시대, 작은 공연 마당
- 팔레트: 벽돌 `#B86655`, 살구 `#E8A04A`, 직물 `#C85C78`, 크림 `#F6E4C8`
- 실루엣: 겹친 처마, 천막, 계단식 광장
- 피할 것: 군중 애니메이션으로 marker를 가림, 대화 말풍선 과밀, 겨울 장식을 기본 구조에 고정
- 이벤트 원칙: 기본 버전이 먼저 완결되어야 하며 겨울은 동일 충돌·진입·sound 좌표 위의 교체 가능한 장식 레이어다.

### 7.3 Nature — 호흡하는 층위

- 콘셉트: 숲, 물, 바람의 층이 이어지는 자연 관찰 정원
- 감정: 평온함, 경이, 회복
- 주요 랜드마크: 큰 수관 아래의 순환 샘
- 보조 공간: 습지 데크, 바람 언덕, 이끼 정원
- 팔레트: 잎 `#3F8057`, 이슬 `#67B7B0`, 하늘 `#83A9D8`, 강조 `#CDEB88`
- 실루엣: 수직 수목과 낮은 물길의 대비
- 피할 것: 지나치게 유기적인 가장자리 때문에 통행 경계가 모호해짐, 입자가 marker보다 밝음
- 이동 균형: 수목 전경은 캐릭터 머리 위만 가릴 수 있고 발·marker·경로는 가리지 않는다.

### 7.4 Urban — 읽을 수 있는 도시 리듬

- 콘셉트: 교통과 신호가 교차하지만 보행 우선으로 정돈된 소형 도시
- 감정: 에너지, 명료함, 발견
- 주요 랜드마크: 시계·신호탑이 있는 중앙 환승 광장
- 보조 공간: 상점가, 옥상 정원 진입부, 작은 작업장
- 팔레트: 아스팔트 `#4E5966`, 석재 `#A8A292`, 유리 `#6C94A8`, 강조 `#F2C14E`
- 실루엣: 각진 수직선, 반복 창, 명확한 횡단 패턴
- 피할 것: 실제 통행 불가 도로를 주 경로처럼 그림, 간판과 신호의 동시 점멸, 회색 단조로움
- 이동 균형: 차도·보도 장식과 실제 이동 규칙을 일치시키고 교차점마다 최소 3타일 시야를 확보한다.

### 7.5 Music — 첫 관문이자 공명의 정원

- 콘셉트: 소리를 만들기보다 듣고 비교하는 공명 정원
- 감정: 초대, 집중, 작은 성취
- 주요 랜드마크: 열린 공명 파빌리온
- 보조 공간: 리듬 다리, 조용한 청취 정원, 파형 아케이드
- 팔레트: 보라 `#7C5CC4`, 남보라 `#50417C`, 크림 `#F4E8CF`, 강조 `#F0C8FF`
- 실루엣: 음파 곡선과 원형 무대, 단순한 반복 기둥
- 피할 것: 음표 폭죽과 강한 네온으로 다른 마을보다 보상성이 커 보임, marker 주변 악기가 소리 정답을 암시함
- 연구 역할: 일반 참여자의 첫 마을임을 월드맵 동선과 안내로 명확히 하되, 해금 뒤 시각적 우월성은 제거한다.
- Block 1 경험: 입구→첫 marker가 짧고, 다음 marker가 한 번에 3~7개 보이며 *(provisional)*, 완료 상태가 진행 방향을 자연스럽게 드러내야 한다.

### 7.6 Lab — 미지의 소리 관측소

- 콘셉트: 알 수 없는 소리를 수집·분석하는 밤의 관측소
- 감정: 신비, 정밀함, 안전한 탐구
- 주요 랜드마크: 중앙 원형 스펙트럼 관측 장치
- 보조 공간: 파형 기록실, 표본 보관실, 옥상 안테나 진입부
- 팔레트: 심청 `#173B5E`, 청록 `#2B7180`, 황동 `#E2B44D`, 별빛 `#D8E8F4`
- 실루엣: 원형 관측 장치, 각진 실험대, 가는 황동 배선
- 기준 콘셉트: `design/concepts/lab-sound-observatory-concept-v1.png`
- 피할 것: 공포 던전처럼 위협적인 뼈·함정·붉은 경고, 실험 장치 발광이 marker보다 강함
- 구현 원칙: 콘셉트 이미지의 분위기와 기능 구역은 참고하되 그대로 타일맵으로 복사하지 않고 48×36 동선과 충돌 규칙으로 재구성한다.

## 8. 월드맵 원칙

- 중앙 공용 시설은 방향 기준점이며 특정 마을보다 시각적으로 보상이 커 보이면 안 된다.
- 여섯 마을의 입구 면적, 라벨 크기, 발광 강도, 움직이는 요소 수를 동급으로 맞춘다.
- Music-first 상태에서는 Music 경로만 활성 안내를 받고 다른 다섯 경로는 동일한 잠금 표현을 쓴다.
- 해금 후에는 여섯 경로의 대비를 같게 하고 최근 방문·진행률은 중립적인 UI 라벨로만 표시한다.
- 중앙→각 마을 입구의 체감 이동 시간 차이는 목표 ±15% 이내다. *(provisional)*
- 마을 배치는 의미론적 “좋음/나쁨”이나 상하 서열로 읽히지 않게 한다.
- 전체 진행률은 여섯 마을의 동일 가중 구조를 시각적으로도 같은 면적의 여섯 조각으로 표현한다.

## 9. 마을 간 매력 균형

서로 다른 정체성은 유지하되 다음 항목의 총량을 맞춘다.

| 항목 | 마을별 기준 |
|---|---|
| 주요 랜드마크 | 1개 |
| 보조 랜드마크 | 2~4개 |
| 강한 환경 애니메이션 | 화면당 최대 4개 권장 |
| 고채도 강조색 면적 | 화면 면적의 5~10% |
| 입구→첫 활성 marker 시간 | 마을 중앙값 간 차이 ±15% 목표 *(provisional)* |
| 활성 marker 평균 탐색 시간 | 마을 간 평균 차이 ±20% 목표 |
| 주 경로 폭 | 동일한 3타일 기준 |

파일럿 검수에서는 5점 매력도 평정의 마을 간 평균 최대 차이 0.75 이하를 provisional 목표로 확인한다. 이 값이 넘으면 가장 높은 마을의 효과를 줄이거나 낮은 마을의 명료성과 완성도를 높인다. 보상을 증액해 시각 불균형을 상쇄하지 않는다.

## 10. 계절·이벤트 레이어

- 기본 맵의 통행, 충돌, 문, sound marker, annotation 좌표가 먼저 승인되어야 한다.
- 이벤트 버전은 교체 가능한 바닥 decal, 지붕 적설, 식생, 조명, 소품, 입자 레이어로 구성한다.
- 이벤트 레이어는 충돌을 새로 만들지 않고 상호작용 영역을 침범하지 않는다.
- 눈·낙엽·꽃잎 입자는 annotation 패널이 열리면 50% 이상 감쇠한다.
- Human 겨울 시장은 기본 Human 맵의 대체물이 아니라 별도 이벤트 표현으로 관리한다.
- 계절마다 특정 마을만 지속적으로 더 화려해지지 않도록 여섯 마을에 동등한 이벤트 예산을 배정한다.
- 한 마을만 계절 이벤트 상태일 때 월드맵 입구에는 작은 비발광 계절 배지를, 공통 UI에는 이벤트 기간 라벨을 표시한다. 입구 크기·잠금 상태·진행률 표현은 바꾸지 않는다.

## 11. 생성 이미지·외부 콘셉트 사용 규칙

- 생성 이미지는 분위기, 재료, 조명, 실루엣 탐색용이며 그대로 게임 자산으로 간주하지 않는다.
- 생성 이미지를 단일 배경으로 바로 넣지 않고 아트 디렉션 또는 레이어 원본으로 사용한다.
- 실제 이동 공간, 문, 주·보조 경로와 상호작용 여백을 먼저 타일 whitebox로 검증한 뒤 이미지를 맞춘다.
- 최종 자산은 최소 `background`, `foreground`, `emissive`, `collision`, `interaction` 레이어로 분리한다. collision과 interaction은 그림이 아니라 논리 데이터로 유지한다.
- 플레이어, NPC, UI, 텍스트, sound marker, 재화·수집 아이템을 배경 이미지에 굽지 않는다.
- 기존 캐릭터·건물·UI 스타일과 투시, 광원, 픽셀 밀도를 대조한다.
- 확대·축소가 필요하면 pixel 요소는 정수 배율과 nearest-neighbor 기준을 사용하고 painted layer의 필터링과 분리한다.
- 텍스트·로고·기호 왜곡, 비일관 원근, 불가능한 문·계단, 반복 무늬 오류를 제거한다.
- 타일 경계, walkable mask, foreground 분리, 충돌 영역을 사람이 다시 설계한다.
- 콘셉트마다 출처, 생성/편집 여부, 날짜, 버전을 기록한다.
- 기존 이미지나 승인 자산을 덮어쓰지 않고 새 버전 파일로 보존한다.
- 연구 참여자에게 노출되는 이미지에는 소리 정답을 암시할 수 있는 구체 사물을 검토한다.

## 12. 구현 단계 공통 체크리스트

### 구조

- [ ] 48×36, 32px 논리 격자와 기존 zone 식별자를 유지한다.
- [ ] 주 경로, 입구, 상호작용 여백이 수치 기준을 충족한다.
- [ ] 보이는 경계와 충돌 경계가 일치한다.
- [ ] 전경 레이어가 플레이어 발과 활성 marker를 가리지 않는다.

### 연구 흐름

- [ ] Music-first 및 그룹별 Block 1 해금 흐름을 일반 참여자 계정으로 검수한다.
- [ ] voluntary skip이 없고 패널 닫기와 technical failure가 저장 없는 미완료 상태로 동작한다.
- [ ] canonical key·DB 중복 방지 같은 향후 기술 제안을 시각 리디자인의 필수 구현으로 취급하지 않는다.
- [ ] 박물관 그룹 분리와 승인된 후보 임계값을 검수한다.
- [ ] 시각 요소가 소리의 의미나 표현을 프라이밍하지 않는다.

### 가독성

- [ ] 한 화면 활성 marker가 목표 3~7개 범위다.
- [ ] 3초, 흑백, 320×180, 모바일 테스트를 통과한다.
- [ ] 소리 marker와 재화가 형태·상태·애니메이션으로 구분된다.
- [ ] 잠금, 활성, 완료, technical failure 상태가 색 없이도 구분된다.

### 균형

- [ ] 여섯 마을의 랜드마크·효과·접근 시간 예산이 비교 가능하다.
- [ ] 월드맵이 특정 해금 마을을 우선 선택하도록 유도하지 않는다.
- [ ] 계절 이벤트가 기본 맵 기능과 충돌하지 않는다.
- [ ] `MAP_REVIEW_SCORECARD.md`의 게이트와 최소 점수를 통과한다.
