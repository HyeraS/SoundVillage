# 도시 마을 2D 픽셀맵 디자인 시안

SoundMimic Village의 `Urban` 존 리스킨을 위한 디자인 콘셉트 3종이다. 첨부된 도시 픽셀맵 3장과 프로젝트의 기존 Nature/Lab 콘셉트를 참고하되, 특정 레퍼런스를 복제하지 않은 신규 구성이다.

## 공통 디자인 규칙

- 완전한 탑다운 2D 픽셀아트. 아이소메트릭·3D·실내 컷어웨이 금지.
- 현재 존 규격인 48×36 논리 타일과 32px 타일 스케일로 옮기기 쉬운 굵은 실루엣.
- 남쪽 중앙 입구에서 모든 구역으로 이어지는 연속 보행 루프.
- 건물, 나무, 가로등, 화단, 벤치, 차량, 울타리, 물은 충돌 오브젝트로 처리.
- 주요 보행로는 최소 캐릭터 두 명 폭을 확보하고, 막다른 길에는 돌아나올 공간을 둔다.
- 각 시안에 황금색 파형 소리 아이템 정확히 6개. 모두 마른 보행 공간에 있고 장애물과 최소 캐릭터 한 명 폭 이상 떨어져 있다.
- 상단 크림색 HUD, 캐릭터 크기, 소리 오브의 시각 언어는 기존 Nature 마을 콘셉트와 통일.

## 시안 1 — Brick & Bloom Civic Square

파일: `01-brick-bloom-civic-square.png`

중앙 시민 광장과 둥근 사각형 도로 루프가 중심인 낮 시간대의 따뜻한 벽돌 마을이다. 시청·베이커리·우체국·꽃집·카페·저층 주택이 광장을 감싸며, 네 곳의 횡단보도가 안쪽 광장과 바깥 상점가를 연결한다.

- 장점: 도시 정체성이 가장 즉시 읽히며 기존 `UrbanRoadNetwork` 구조에 가장 쉽게 이식 가능.
- 동선: 남쪽 산책로 → 중앙 광장 → 서쪽 상점가 → 북쪽 관공서 → 동쪽 주거 포켓 → 남동 버스 정류장으로 하나의 큰 루프.
- 충돌 핵심: 도로섬 화단, 분수, 가로수, 주차 차량. 횡단보도 네 곳은 반드시 열어 둔다.
- 블록 해금 권장 순서: 남쪽 상점가 → 서쪽 상점가 → 중앙 광장 → 동쪽 주거지 → 북쪽 시민구역 → 북동 베이커리 구역.
- 추천도: **1순위.** 다른 낮 배경 마을과 가장 자연스럽게 이어지고, 게임 구현 위험이 가장 낮다.

## 시안 2 — Canal Station Promenade

파일: `02-canal-station-promenade.png`

북쪽의 작은 역과 오른쪽 세로 운하를 중심으로 한 역세권 산책 마을이다. 서쪽은 벽돌 상점가, 동쪽은 도서관·포켓파크·운하 산책로이며 두 개의 넓은 돌다리로 연결된다.

- 장점: 다리와 운하가 탐험 순서를 자연스럽게 유도해 소리 찾기 동선이 가장 재미있다.
- 동선: 남쪽 역전대로 → 서쪽 상점 골목 → 북쪽 역 광장 → 위쪽 다리 → 동쪽 산책로 → 아래쪽 다리 → 입구 복귀.
- 충돌 핵심: 운하와 철로는 완전 차단. 두 다리는 최소 3타일 폭으로 두어 캐릭터와 소리 아이템이 겹쳐도 병목이 생기지 않게 한다.
- 블록 해금 권장 순서: 남쪽 대로 → 서남 시장 → 서쪽 카페 → 북쪽 역 → 북동 공원 → 동쪽 운하 산책로.
- 구현 주의: 세 시안 중 물·다리 충돌 마스크 작업량이 가장 크다.

## 시안 3 — Pocket Park & Night Market Boulevard

파일: `03-pocket-park-night-market.png`

큰 포켓파크와 상점가, 소형 극장, 버스 정류장이 결합된 블루아워 마을이다. 따뜻한 창문과 가로등으로 밤 분위기를 내되, 바닥과 장애물은 명확하게 읽히도록 밝기를 유지한다.

- 장점: 분위기와 기억점이 가장 강하고, Urban의 군중·차량·상점 소리를 자연스럽게 배치할 수 있다.
- 동선: 남쪽 중앙 보행축 → 공원 순환로 → 서쪽 야시장 상점가 → 북쪽 상점가 → 동쪽 극장 → 남동 주차장 외곽 → 입구 복귀.
- 충돌 핵심: 공원 나무 군집, 정자, 극장, 주차 차량. 공원 안쪽 곡선길과 중앙 세로 보도는 반드시 연결한다.
- 블록 해금 권장 순서: 남쪽 진입광장 → 공원 남쪽 → 공원 북쪽 → 북서 상점가 → 북동 생활상점 → 동쪽 극장 구역.
- 구현 주의: 실제 게임에서는 소리 오브·캐릭터가 묻히지 않도록 야간 오버레이를 약하게 유지한다.

## 구현 핸드오프

이 PNG들은 완성 스프라이트시트가 아니라 레이아웃·색감·랜드마크·동선 기준 이미지다. 실제 연결 시 다음을 고정한다.

1. 게임·데이터 로직, 6블록 해금, 소리 수집 콜백은 변경하지 않는다.
2. 지면 렌더와 충돌 마스크를 분리한다. 장식 그림자나 차선은 충돌시키지 않고, 건물 발자국·차량 차체·나무줄기·가구 본체만 충돌시킨다.
3. 소리 아이템 스폰 후보는 `walkable && !road && !water && distanceFromSolid >= 1 tile` 조건으로 제한한다.
4. 남쪽 입구부터 거리순으로 6블록을 열어 안개가 사라질 때 자연스러운 탐험 순서가 되게 한다.
5. 기존 `public/assets/world/urban/kenney_tilemap.png`와 `URBAN_KENNEY_*` 등록 에셋을 우선 재사용하고, 콘셉트에 없는 작은 소품을 임의로 늘리지 않는다.
