# SoundMimic Village — 동물 마을 농장형 맵 3안

## 공통 기준

- 2D 탑다운, 32px 타일 기준
- 기존 동물 마을과 같은 캐릭터·건물·농장 스프라이트 사용
- 캐릭터 충돌은 전신이 아니라 발밑 18×12px 기준
- 건물, 울타리, 물, 작물 줄, 절벽은 통과 불가
- 막힌 영역마다 우회로 또는 열린 게이트를 배치
- 떠다니는 발자국 모양의 사운드 아이템은 주 동선과 랜드마크 사이에 배치
- 실제 게임 연결 시 30×20 프리뷰를 기존 48×36 제작 규격으로 확장

## 01 해바라기 공동농장 — 추천 기본안

중앙 풍차 광장을 허브로 삼는 방사형 구조. 남쪽 입구에서 목적지가 곧바로 보이고, 광장에서 각 생산 구역으로 갈라진다. 처음 플레이하는 참여자에게 가장 읽기 쉽고 현재 블록 순차 해금 구조를 옮기기 수월하다.

- 장점: 길 찾기 명료, 사운드 아이템 노출 조절 용이, 충돌 구조 단순
- 유의점: 탐색의 놀라움은 세 안 중 가장 낮음
- 권장 블록 순서: 광장 → 닭장 → 서쪽 목장 → 온실·밭 → 연못 목장

## 02 버들개울 목장마을 — 탐색 강화안

S자 개울과 두 개의 다리가 구역을 나누는 순환형 구조. 목표 아이템이 보이지만 바로 갈 수 없는 순간을 만들어, 작은 우회와 발견의 재미가 가장 크다.

- 장점: 기억에 남는 풍경, 자연스러운 탐색, 물가 사운드와 높은 궁합
- 유의점: 다리 주변 병목과 모바일 조작 난이도 검증 필요
- 권장 블록 순서: 남쪽 과수원 → 서쪽 돼지목장 → 강변 헛간 → 동쪽 소목장 → 북쪽 온실

## 03 구름언덕 다락농장 — 진행 연출안

남쪽 저지대에서 북쪽 풍차 언덕으로 올라가는 단계형 구조. 실제 높이 차이는 사용하지 않고 절벽선과 계단만으로 상승감을 표현한다. 구역이 열릴 때마다 위쪽 풍경이 드러나므로 진행 연출이 선명하다.

- 장점: 블록 해금과 공간 서사가 일치, 마지막 랜드마크의 보상감이 큼
- 유의점: 절벽 충돌과 계단 통로를 가장 세밀하게 다듬어야 함
- 권장 블록 순서: 남쪽 목초지 → 아랫마을 → 중단 온실 → 언덕밭 → 풍차 정상

## 선택 가이드

실험 참여자가 빠르게 이해하고 전사 작업에 집중하는 것이 우선이면 **01 해바라기 공동농장**을 추천한다. 게임다운 탐색 경험을 강화하려면 02, 블록 해금의 성취감을 크게 만들려면 03이 적합하다.
