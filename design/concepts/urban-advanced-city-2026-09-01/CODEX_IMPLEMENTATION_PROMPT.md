# Codex 구현 프롬프트 — Urban 2안 Midnight Metro Media Core

SoundMimic Village의 `Urban` 존을 아래 확정 디자인으로 완전히 리스킨하고, 실제 게임 흐름에 연결해 주세요.

## 목표

현재의 Kenney 기반 도시 마을을 **2안 `Midnight Metro Media Core`**와 최대한 가깝게 재구현합니다. 결과는 차가운 인디고·네이비·시안 계열의 첨단 대도시 중심지여야 하며, 고가 메트로·현대식 고층 건물·미디어 파사드·유리 푸드코트·현대 극장·전기버스 환승 공간이 명확히 보여야 합니다. 기존의 따뜻하고 소박한 마을, 오래된 상점가, 농촌·시장 분위기가 남지 않게 하세요.

작업은 디자인만 흉내 내는 프리뷰로 끝내지 말고, 실제 `Urban` 존 진입·이동·충돌·6블록 해금·소리 수집·전사 패널·완료/퇴장 흐름까지 제품 코드에 연결하고 검증해야 합니다.

## 먼저 읽을 자료

- `AGENTS.md`
- `PROJECT_SUMMARY.md`
- 확정 디자인: `design/concepts/urban-advanced-city-2026-09-01/02-midnight-metro-media-core.png`
- 디자인 설명: `design/concepts/urban-advanced-city-2026-09-01/README.md`
- 생성 의도: `design/concepts/urban-advanced-city-2026-09-01/PROMPTS.md`
- 현재 Urban 구현: `components/ZoneMap.js`의 `URBAN_*`, `buildUrbanZone`, `UrbanRoadNetwork`, Urban 스폰 제외·충돌·렌더 분기
- 현재 Urban 에셋: `components/AssetRegistry.js`의 `URBAN_KENNEY_*`, `URBAN_SOUND_ICONS`
- 전용 존 엔진 선례: `components/MusicZoneMap.js`, `components/NatureZoneMap.js`, `components/AnimalZoneMap.js`, `components/LabZoneMap.js` 및 대응 `lib/*Village.js`
- 실제 분기: `app/page.js`의 zone 렌더 선택부

이 저장소는 Next.js 16.2.7이며 훈련 데이터의 일반적인 Next.js와 다를 수 있습니다. 코드를 쓰기 전에 `node_modules/next/dist/docs/`에서 이번 작업에 해당하는 App Router, Client Component, 이미지/정적 에셋 관련 문서를 읽고 현재 버전의 규칙을 따르세요.

워킹 트리에 다른 작업의 미커밋 변경이 많이 있습니다. 먼저 `git status`와 관련 파일 diff를 확인하고, 사용자 변경을 덮어쓰거나 되돌리지 마세요. Urban 작업과 무관한 파일은 수정하지 않습니다.

## 절대 보존할 게임 규칙

- Supabase, 사운드 메타데이터, A/B 그룹 필터, `sound_id`, 블록 진행, 수집 콜백, AnnotationPanel, Museum 이동, 완료 집계 로직을 변경하지 않습니다.
- `Urban`에는 블록이 6개지만 소리 아이템이 6개뿐인 것이 아닙니다. 콘셉트 이미지의 오브 6개는 여섯 구역을 나타내는 대표 표식입니다. 런타임에서는 현재 그룹의 실제 Urban 사운드를 **누락 없이 전부** 스폰하고, 각 사운드의 기존 `block` 값을 유지하세요.
- 동일한 zone·그룹·sound 목록이면 재입장 후에도 아이템 배치가 같아야 합니다.
- 잠긴 블록은 기존과 동일하게 진입/수집할 수 없고, 입구에서 가까운 블록부터 자연스럽게 열린다는 인상을 유지합니다.
- 방향키/WASD, 모바일 D-pad, ESC 퇴장, Enter 수집, annotation 중 입력 잠금, 완료/퇴장 모달을 보존합니다.
- 캐릭터는 건물, 차량, 화단, 나무, 가로등 밑동, 장벽, 철도 구조물 등을 통과할 수 없어야 합니다. 도로·보도·광장처럼 실제 이동 가능한 지면에서는 자연스럽게 이동할 수 있어야 합니다.

## 구현 방향

`ZoneMap.js`에 더 많은 Urban 전용 코드를 덧붙이기보다, 다른 완성형 존과 같은 전용 구조를 우선 사용하세요.

- `components/UrbanZoneMap.js`: 입력, 플레이어 이동, 추적 카메라, HUD, D-pad, 수집/퇴장/완료 연결
- `lib/urbanVillage.js`: 결정론적 맵 생성, 정적·전경 렌더, 충돌, 보행 가능 영역, 아이템 스폰, 잠금 안개에 필요한 순수 로직
- `app/page.js`: `activeZone === 'Urban'`일 때 `UrbanZoneMap`을 선택하는 최소 분기

공용 `PixelChar`, `ZoneHUD`, `DPad`, `CompleteModal`, `ExitConfirmModal`, `TILE`, `SPEED`, `overlaps`는 재사용하세요. 전용 구조가 실제 코드 상태에서 명백히 부적절하다면 더 안전한 구조를 선택해도 되지만, 그 이유와 트레이드오프를 최종 보고에 적으세요. 기존 `ZoneMap.js`의 Urban 구현은 새 엔진 검증 전에는 삭제하지 말고, 새 분기가 안정적으로 동작한 뒤에도 무관한 대규모 정리는 하지 마세요.

## 맵·카메라 규격

- 논리 월드: 현재와 같은 48×36 타일, `TILE=32` 기준을 유지합니다.
- 런타임 뷰: 기존 전용 존들과 같은 플레이어 추적 카메라를 사용하고, 세로 약 18타일이 보이는 확대감과 화면 가장자리 clamp를 유지합니다. 콘셉트 PNG 전체를 한 화면 배경으로 붙이지 마세요.
- 모든 픽셀 그래픽은 정수 그리드에 맞추고 `imageSmoothingEnabled=false` 또는 동등한 nearest-neighbor 처리를 사용합니다. CSS/Canvas/SVG의 비정수 배율 때문에 픽셀이 흐려지지 않게 하세요.
- 상단 HUD 높이와 카메라 계산이 겹치지 않아 캐릭터가 HUD 아래로 가려지지 않게 합니다.
- 남쪽 중앙에 명확한 입구와 스폰 지점을 두고, 입장 직후 퇴장 판정이 다시 뜨지 않도록 충분히 안쪽에 스폰합니다.

## 확정 디자인을 맵 구조로 번역

이미지 자체에는 HUD·캐릭터가 합쳐져 있으므로, PNG를 평면 배경으로 직접 사용하지 마세요. 디자인을 독립적인 지면·건물·오브젝트·발광·전경 레이어로 재구성합니다.

- 북쪽 끝: 고가 메트로 플랫폼과 정차한 전동차. 중앙 계단/출입구가 넓은 메트로 콘코스로 연결됩니다. 철도와 플랫폼 외곽은 충돌 영역이지만 계단과 콘코스는 보행 가능합니다.
- 북서/북동/좌우 가장자리: 현대식 고층·중층 건물. 평지붕, 유리 커튼월, 옥상 HVAC·태양광·안테나, 반복되는 창문 불빛으로 높이를 표현하되, 탑다운 시점과 캐릭터 가독성을 해치지 않습니다.
- 중앙: 남북 보행축과 동서 보행축이 교차하는 넓고 읽기 쉬운 환승 광장. 시안처럼 중앙 분수/빛 기둥은 랜드마크로 두되 통로를 막지 않습니다.
- 서쪽: 미디어광장과 현대 오피스. 추상적인 시안·바이올렛 디지털 패널을 사용하되 읽을 수 있는 글자나 브랜드는 넣지 않습니다.
- 동쪽: 유리 푸드코트·환승 공간·전기버스 베이.
- 남동: 현대식 극장 또는 미디어홀. 오래된 마을 극장처럼 보이지 않도록 평지붕·곡면/직선 유리 파사드·차가운 조명을 사용합니다.
- 남서: 현대 업무·문화 건물, e-스쿠터/자전거 도크와 작은 광장.
- 도로는 차콜·네이비, 보도는 블루그레이, 유리는 시안, 발광은 쿨 화이트와 제한적인 바이올렛으로 구성합니다. 따뜻한 빛은 소수의 창문에만 대비색으로 사용합니다.
- 녹지는 정돈된 가로수와 사각 플랜터 위주로 제한합니다. 공원·꽃·잔디가 도시보다 더 강하게 보이면 안 됩니다.
- 사이버펑크, 과도한 네온, 디스토피아, 오염, 폐허 느낌은 피합니다. 목표는 현재 또는 가까운 미래의 깨끗하고 발전된 도시입니다.

## 6블록과 탐험 동선

현재 3열×2행 블록 체계와 실제 `sound.block` 값을 보존하되, 경계선을 눈에 보이는 베이지 격자로 그리지 않습니다. 도로, 건물 사이 보행축, 광장 경계로 구역 전환이 자연스럽게 느껴지게 하세요.

권장 탐험 순서는 남쪽에서 시작해 다음과 같이 확장됩니다.

1. 남쪽 중앙 입구·도착 광장
2. 남서 업무·문화 구역
3. 남동 극장·전기버스 구역
4. 중앙/북서 미디어광장
5. 중앙/북동 유리 푸드코트·환승 구역
6. 북쪽 메트로 콘코스·고층 타워 아케이드

모든 블록에 실제 그룹 기준 최대 약 15개의 아이템이 배치될 수 있는 충분한 보행 후보 타일이 있어야 합니다. 후보가 부족할 때 같은 좌표에 아이템이 중복되는 폴백은 허용하지 마세요.

## 소리 아이템 표현과 스폰 안전성

- 디자인 시안처럼 어두운 사각 배지 없이, 작은 시안-화이트 원형 글로우·흰색 파형·바닥 타원 그림자로 표현합니다.
- 기존 active/locked/done 상태와 부유 애니메이션을 유지합니다. 잠금 상태는 형태가 사라지지 않으면서도 명확히 비활성으로 읽혀야 합니다.
- 스폰 후보는 최소한 `walkable && !roadLane && !rail && !water && !solid && distanceFromSolid >= 1 tile`을 만족해야 합니다.
- 출입구, 계단, 횡단보도 중앙, 좁은 병목, 화면 밖 전경 아래에는 스폰하지 않습니다.
- 각 아이템은 캐릭터가 실제로 접근할 수 있어야 합니다. 단순히 충돌 영역 밖인지만 보지 말고 남쪽 스폰에서의 경로 연결성을 검사하세요.

## 에셋과 렌더링

- 현재 저장소의 에셋을 먼저 재사용하되, 기존 `URBAN_KENNEY_*`의 따뜻하고 오래된 건물 표현이 확정 시안과 맞지 않으면 억지로 확대 재사용하지 마세요.
- 현대 건물·지면은 16px 또는 32px 네이티브 그리드의 코드 기반 픽셀 드로잉과 재사용 가능한 작은 로컬 스프라이트를 조합해도 됩니다.
- 새 PNG 에셋이 필요하면 `public/assets/urban-city-v2/` 아래에 역할별로 저장하고 manifest/source 정보를 함께 남기세요. 외부 에셋을 임의 다운로드하거나 라이선스가 불명확한 리소스를 사용하지 않습니다.
- 정적 지면·건물은 오프스크린 캔버스에 프리렌더하고, 매 프레임 전체 맵을 불필요하게 다시 그리지 마세요. 발광·아이템·캐릭터처럼 움직이는 요소만 동적 레이어로 처리합니다.
- 높은 파사드나 플랫폼 전경은 캐릭터 y 위치에 따라 자연스럽게 가려지도록 전경 레이어 또는 y-sort를 사용합니다. 캐릭터가 건물 위에 떠 보이거나 완전히 사라지지 않게 하세요.
- 공용 HUD를 전역으로 차갑게 바꾸지 마세요. 필요하면 Urban의 `ZONE_META` 강조색만 쿨 시안으로 조정하되, 해당 값의 WorldMap·HUD·진입 큐 사용처를 먼저 확인하고 Urban 외 존이 변하지 않았는지 검증하세요.

## 필수 검증

구현 후 눈으로만 확인하지 말고 자동 검증과 실제 브라우저 검증을 모두 수행하세요.

### 자동 검증

- 동일 입력에서 맵과 아이템 좌표가 결정론적인지
- 모든 건물·오브젝트·아이템이 맵 경계 안인지
- 남쪽 입구에서 모든 보행 구역과 모든 활성 아이템까지 경로가 존재하는지(BFS 등)
- 실제 `sound_metadata.json`의 Urban A/B 데이터를 각각 넣었을 때 모든 아이템이 누락 없이 배치되는지
- 각 6블록이 필요한 스폰 용량을 갖는지
- 아이템이 도로 차선·철도·건물·차량·물·고정 소품·병목에 겹치지 않는지
- 캐릭터가 모든 solid를 통과하지 못하고, 보도·광장·횡단보도·열린 계단은 통과할 수 있는지
- 새 Urban 전용 production test를 추가하고 `package.json`에 명확한 실행 스크립트를 연결하세요.

### 브라우저 검증

- 전용 영구 프리뷰/검증 라우트(예: `app/urban-test`)를 만들어 실제 게임과 같은 props·카메라·HUD·아이템 상태를 확인합니다.
- 1440×844, 1920×1080, 대표 모바일 세로 화면에서 픽셀 선명도, 카메라 clamp, HUD, D-pad를 확인합니다.
- 실제 앱에서 `ALLAUDIO_A`와 `ALLAUDIO_B`로 로그인해 WorldMap → Urban 진입 → 이동/충돌 → 아이템 수집 → AnnotationPanel 열기/닫기 → 블록 잠금 → ESC 퇴장을 확인합니다.
- 콘솔 에러와 hydration 오류가 없어야 합니다.
- 검수 스크린샷은 `_review/urban-advanced-city/`에 저장합니다.
- `npm run lint`, Urban 전용 테스트, 프로덕션 빌드를 실행합니다. 기존의 무관한 실패가 있으면 새 변경으로 인한 것인지 분리해 보고하세요.

## 완료 기준

다음이 모두 충족될 때만 완료로 보고하세요.

- 첫 화면만 봐도 따뜻한 ‘마을’이 아니라 차가운 현대 대도시로 읽힌다.
- 확정 2안의 고가 메트로, 고층 유리 건물, 중앙 보행축, 미디어광장, 현대 극장, 전기버스 공간이 게임 맵으로 번역되어 있다.
- 기존 맵들과 픽셀 굵기·캐릭터 비율·탑다운 시점·HUD 구조가 어울린다.
- 캐릭터 이동과 충돌이 자연스럽고 모든 실제 사운드 아이템이 도달 가능하다.
- 6블록 해금과 수집/전사/완료/퇴장 흐름에 회귀가 없다.
- 데스크톱과 모바일에서 픽셀이 흐려지거나 HUD·카메라가 깨지지 않는다.
- 검증 결과와 스크린샷으로 위 기준을 증명한다.

## 작업 방식과 최종 보고
