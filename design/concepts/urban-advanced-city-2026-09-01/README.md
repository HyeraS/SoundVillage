# Urban Advanced City — 2D 픽셀맵 V2

기존 도시 마을 3안을 현대·첨단 대도시 방향으로 전면 재구성한 시안이다. 새 레퍼런스에서는 고층 스카이라인, 현대 교통, 유리·철골·콘크리트 소재, 발전된 도시 인프라만 참고했다. 레퍼런스의 원근 시점과 아이소메트릭 구도는 사용하지 않았다.

## 공통 규칙

- 기존 시안과 동일한 4:3 탑다운 2D 게임 뷰와 굵은 픽셀 스케일.
- 48×36 논리 타일 맵으로 옮기기 쉬운 건물 발자국과 보행 공간.
- 남쪽 중앙 입구, 최소 캐릭터 2명 폭의 주요 보행로, 전 구역 연결 루프.
- 건물·화단·가로등·차량·물·철도 구조물은 명확한 충돌 실루엣으로 표현.
- 각 시안에 접근 가능한 청록색 파형 소리 아이템 정확히 6개.
- 색상은 스틸 블루, 블루그레이, 차콜, 시안, 슬레이트 중심. 따뜻한 색은 창문 조명 정도로만 제한.
- 테라코타 지붕, 목조 오두막, 베이커리 마을, 전통 시장, 농장 요소는 제외.

## 1안 — Azure Glass Tech Plaza

파일: `01-azure-glass-tech-plaza.png`

유리 타워와 스마트 시민광장이 중심인 주간 업무지구다. 중앙 도로 루프·네 개 횡단보도·메트로 캐노피 구조로, 기존 Urban 도로 시스템에 가장 안정적으로 이식할 수 있다.

- 도시 요소: 유리 커튼월, 평지붕, 태양광 패널, 스카이브리지, 자율주행 셔틀, 충전 볼라드.
- 동선: 남쪽 모빌리티 광장 → 중앙 스마트 광장 → 서쪽 오피스 → 북쪽 메트로 → 동쪽 혁신센터 → 입구.
- 구현 난이도: 낮음. 중앙 도로 루프와 보도 경계가 명확하다.
- 추천 용도: 실제 게임 이식을 빠르게 진행할 때.

## 2안 — Midnight Metro Media Core

파일: `02-midnight-metro-media-core.png`

고가 메트로와 현대 미디어·엔터테인먼트 건물을 결합한 야간 대도시 중심부다. 세 시안 중 가장 밀도 높고 ‘첨단 도시’라는 인상이 강하다.

- 도시 요소: 고가철도, 미디어 파사드, 유리 푸드코트, 현대 극장, 전기버스 베이, 스마트 가로등.
- 동선: 남쪽 중앙축 → 서쪽 미디어광장 → 북쪽 메트로 콘코스 → 동쪽 환승광장 → 극장 → 입구.
- 구현 난이도: 중간. 야간 명도와 고가철도 전경 레이어를 세심하게 조정해야 한다.
- 추천도: **사용자 요청 적합도 1순위.** 발전된 대도시 시대감이 가장 명확하다.

## 3안 — Blue Harbor Innovation District

파일: `03-blue-harbor-innovation-district.png`

운하·연구시설·친환경 에너지·현대 교통을 묶은 워터프런트 혁신지구다. 첨단 도시이면서도 밝고 쾌적한 방향이다.

- 도시 요소: 연구동, 데이터센터, 곡면 컨벤션홀, 전기 트램, 태양광, 소형 풍력, 현대식 보행교.
- 동선: 남쪽 혁신 산책로 → 서쪽 연구 캠퍼스 → 북쪽 트램광장 → 상부 다리 → 동쪽 워터프런트 → 하부 다리 → 입구.
- 구현 난이도: 중간 이상. 운하·다리·철도 충돌 마스크가 필요하다.
- 추천 용도: 미래적이지만 야간·네온이 아닌 밝은 도시를 원할 때.

## 구현 핸드오프

1. PNG는 최종 스프라이트시트가 아니라 레이아웃·시대감·랜드마크·색감 기준 이미지로 사용한다.
2. 6블록 해금과 소리 수집 로직은 그대로 두고 Urban 렌더와 충돌 마스크만 교체한다.
3. 소리 아이템 후보는 `walkable && !vehicleLane && !water && !rail && distanceFromSolid >= 1 tile`로 제한한다.
4. 높은 건물은 북쪽과 외곽에 집중시켜 캐릭터·아이템·출입구를 가리지 않게 한다.
5. 유리창 발광, 젖은 바닥 반사, 디지털 패널은 장식 레이어로만 처리하고 충돌시키지 않는다.
6. 실제 픽셀 에셋 제작 시 16px 또는 32px 네이티브 그리드를 정수배로 확대한다.
