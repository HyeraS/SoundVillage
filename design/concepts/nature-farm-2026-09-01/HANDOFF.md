디자인 추천은 **02 물소리 개울 농장**이다. 물의 연속된 실루엣이 Nature 정체성을 만들고, 밭·온실·작은 집이 Farm 분위기를 유지한다. Animal 마을의 중앙 연못·우리 중심 구성과도 구별된다. 더 전형적인 농장 광장을 원하면 01, 숲속 산책 감각을 우선하면 03이 적합하다.

## 공통 시각 방향

- 3D나 아이소메트릭이 아닌, 건물의 정면이 조금 보이는 2D 탑다운 RPG 시점.
- 동물의 숲에서 따뜻한 생활감과 작은 마을의 공간감을 참고하되, 캐릭터나 고유 시설을 복제하지 않음.
- 첨부 레퍼런스의 읽기 쉬운 픽셀 덩어리, 둥근 수관, 작물과 목책의 반복 리듬을 반영.
- 기존 Nature / Animal / WorldMap 기준 화면의 올리브·세이지 잔디, 모래색 길, 청록·슬레이트 지붕, 크림 HUD를 참고.
- 실내 벽이나 사각 울타리로 전체를 감싸지 않고, 숲과 길이 화면 바깥으로 이어지는 야외 마을로 구성.
- 밭은 농장 테마를 표현하는 환경이다. 재배 시스템·인벤토리·동물 관리 기능을 추가하는 제안은 아니다.
- 소리 아이템은 공통 금빛 구슬과 중립적인 파형으로 표현. 특정 소리의 정답을 암시하는 이름이나 그림을 넣지 않음.

## 현재 코드에서 확인한 규격과 이식 목표

| 항목 | 확인한 현재 규격 / 제안 |
|---|---|
| Nature 논리 맵 | 48 × 36 타일 |
| 월드 타일 | 32 × 32 px |
| Nature 원본 지형 타일 | 16 × 16 px를 32 × 32 world px로 표시 |
| 월드 캔버스 | 1536 × 1152 world px |
| 카메라 기준 | 24 × 18 타일 |
| 공통 PixelChar 표시 영역 | 72 × 88 world px. 이미지 속 임시 여행자로 교체하지 않고 현재 캐릭터를 재사용 |
| Nature 발밑 충돌 | 현재 PLAYER_BOX 18 × 10 px; canStand는 y−11 ~ y−1 검사 |
| 제안 주 통행 폭 | 3타일 이상, 입구·중심부는 더 넓게 |
| 제안 보조 통행 폭 | 2타일 이상 |
| 건물 문 앞 | 3 × 3타일 접근 영역 확보 |
| 소리 아이템 주변 | 최소 1타일 여백과 주 접근 방향 2타일 확보 |

위 표의 통행 폭·여백은 **향후 구현 목표**다. 생성된 PNG를 좌표 그리드로 측정해 충족 여부를 검증한 결과가 아니다. 이미지의 굵은 픽셀 표현 역시 시각 방향이며 정확한 16px 원본 스프라이트나 타일맵으로 제작된 것은 아니다.

전체 마을 배치를 비교하기 위해 세 이미지 모두 맵 전체를 보여 준다. 실제 플레이 화면의 카메라는 기존 24 × 18타일 범위를 유지하고 캐릭터를 따라 이동해야 한다. 전체 맵을 화면에 고정 축소하면 기존 마을과 캐릭터 크기가 달라지므로 피한다.

## 이동·충돌 설계

1. 길과 열린 잔디는 통행 가능하다. 꽃·낮은 풀·작은 지면 무늬는 장식으로 취급한다.
2. 건물 몸체, 나무줄기, 바위, 우물, 온실, 작물 밭, 울타리, 수면은 통과하지 못한다. 시각적인 경계와 맞는 별도 collision 데이터로 표현한다.
3. 나무는 수관 전체가 아니라 줄기와 뿌리 쪽을 충돌 기준으로 삼는다. 수관 아래를 걸을 수 있는 경우 가림 처리와 아이템 시인성을 별도로 설계한다.
4. 다리에서는 바닥만 통행 가능하고 난간은 충돌한다. 양쪽 접속 지점에 풀·돌·울타리가 걸쳐 보행을 막지 않아야 한다.
5. 밭과 과수원은 최소 한 곳의 명료한 개구부를 갖는다. 통과 불가능한 밭 내부나 울타리 속에 소리가 생성되지 않도록 한다.
6. 본 이미지를 배경 한 장으로 붙이는 것만으로는 충돌이 생기지 않는다. terrain / props / collision / foreground / sound markers / character / HUD를 분리해 구현한다.
7. 맵에 보이는 순환 길은 완전 개방 상태의 구상이다. 각 잠금 단계에서 스폰 → 모든 활성 소리 → 출구가 연결되는지 별도의 탐색 검사와 실제 조작 검증이 필요하다.

## 게임 흐름 보존

- 원래 흐름인 탐험 → 소리 발견 → 재생 및 의성어 표현 → 자신감 제출 → Museum 흐름을 유지.
- 그룹 필터, sound_id, 블록 개수·순서, 잠금/안개, 수집·전사·투표·저장 로직은 이번 디자인의 변경 대상이 아니다.
- 이미지의 구역 6 / 6은 전 영역이 보이는 디자인 검토 상태다. 실제 게임의 초기 상태를 바꾸자는 뜻이 아니다.
- 이미지 속 소리 구슬은 시각적 배치 예시다. 구슬 수가 실제 데이터 개수, 블록 수 또는 카메라 내 표시 제한을 의미하지 않는다.
- 배경 소품과 그 위치의 실제 소리를 일대일로 연결하지 않는다. 환경이 전사 답변을 유도하지 않도록 소리 데이터와 장식의 의미를 분리한다.
- UI와 구슬이 이미지 안에 함께 보이지만, 제품에 연결할 때는 현재 ZoneHUD / DPad / PixelChar와 동적 소리 렌더를 재사용한다. PNG에 그려진 UI·구슬을 그대로 이중 표시하지 않는다.
- 버튼 글자와 구슬 표현은 시안용이다. 현재 공통 인터랙션 정책의 변경을 승인하거나 구현한 것은 아니다.

## 확인한 범위와 남은 검증

완료: 프로젝트 요약 및 맵 엔진 규격 확인, 기존 마을 3종 기준 이미지 대조, 시안 3종 생성·육안 검수, 01의 지나치게 세밀한 표면 묘사 단순화, 03의 연못 위 구슬을 마른 길로 이동.

미수행: 실제 타일·스프라이트 제작, 충돌 마스크 작성, 이동 경로 도달성 검사, 픽셀 격자·배율의 정량 일치 검사, 모바일 카메라·성능 검증, 게임 연결 및 배포. 실행 코드를 수정하지 않았으므로 런타임 테스트는 수행하지 않았다.

이미지는 원본 해상도를 그대로 저장했다. 생성 결과는 개발용 월드 캔버스 규격과 별개이며, 완성 타일맵 또는 바로 출시 가능한 배경 에셋으로 간주하지 않는다. 최종 선택 뒤 기존 에셋 우선으로 재구성하고, 부족한 소품만 동일 원본 픽셀 규격으로 제작하는 것이 후속 작업이다.
