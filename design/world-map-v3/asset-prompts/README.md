# Sound Archive Garden v3 ImageGen prompts

All new masters were created with the built-in ImageGen workflow on 2026-09-20.
The reference image was used only for visual style, camera angle, palette,
lighting, and landmark identity. Runtime sprites are not crops from the old
flattened world map.

The exact prompts are recorded in `ASSET_SOURCES.md` under the review folder.
The generation groups are:

- eight unique landmark calls: Sound Library, Home, Animal, Nature, Human,
  Urban, Music, and Lab;
- one eight-cell nature atlas call;
- one eight-cell props/fence/water atlas call.

Every call required genuine transparency, a consistent three-quarter top-down
view, warm upper-left lighting, complete silhouettes, and no text/UI/watermark.
