# 동물 마을 농장 리스킨 3안

## 공통 기준

- 2D 탑다운, 32px 타일 감각, 굵고 읽기 쉬운 픽셀 실루엣
- 실내 방이 아닌 야외 마을로 보이도록 건물·울타리·농지·물·나무를 구역 단위로 구성
- 캐릭터 발밑 충돌 박스 기준으로 건물, 울타리, 작물, 물, 절벽을 통과하지 못하게 설계
- 모든 장애물 주변에 우회 동선 또는 되돌아갈 수 있는 여유 공간 확보
- 떠 있는 소리 아이템은 갈림길, 랜드마크, 다리 앞처럼 시야가 열리는 지점에 배치
- 첨부 레퍼런스는 분위기, 픽셀 밀도, 길의 가독성만 참고하고 맵과 오브젝트 배치는 새로 설계

## 01 해바라기 공동농장

중앙 풍차 광장에서 네 구역으로 갈라지는 기본안이다. 4차 수정에서는 소리 아이템 전용 공터 네 곳과 중간 밀도를 유지하면서, 맨 왼쪽 아래에 작은 주거 구역을 복원했다. 각 공터는 약 3×3타일이며 적어도 세 방향에서 접근할 수 있다.

- 강점: 가장 명료한 동선, 안정적인 충돌 제작, 소리 아이템 발견·접근성
- 주의: 반복 플레이에서는 탐색 변화가 작을 수 있음
- 추천 용도: 실제 게임 연결의 1순위 베이스

### 1번 개선 내역

- 중심 풍차·헛간·농가·온실·연못·농지는 유지
- 맨 왼쪽 아래 농지·농산물 카트 자리에 파란 지붕과 붉은 지붕 집 두 채만 추가
- 전체 장식 밀도는 최초안의 약 55~60%로 조정
- 주 동선 폭을 3~4타일로 확대
- 서쪽, 동쪽, 남서쪽, 남동쪽에 소리 아이템 공터 배치
- 공터 내부가 아닌 가장자리에 나무·벤치·우물·꽃과 작은 생활 소품 배치
- 플레이 맵의 실제 충돌·아이템 좌표도 수정된 공간 구성에 맞춰 재배치
- 왼쪽 위 목장의 양은 서로 겹치지 않게 분리하고, 머리·몸통·다리 실루엣이 한 개체로 읽히도록 수정

## 02 버들개울 목장마을

S자 개울과 두 다리를 중심으로 순환하는 탐색 강화안이다. 멀리 보이는 소리 아이템에 도달하기 위해 다리를 찾아가는 작은 모험이 생긴다.

- 강점: 발견과 우회의 재미, 동물 마을의 자연 친화적 인상
- 주의: 물가 충돌과 다리 입구의 정밀한 튜닝 필요
- 추천 용도: 탐색 경험을 우선할 때

## 03 구름언덕 다락농장

남쪽 목초지에서 북쪽 풍차 언덕으로 올라가는 단계 해금형이다. 실제 높이는 없지만 절벽 띠와 계단을 이용해 진행감을 전달한다.

- 강점: 블록 해금과 공간 상승의 결합, 풍경 변화가 큼
- 주의: 단차 경계와 계단 충돌 규칙이 추가로 필요
- 추천 용도: 퀘스트 진행 연출을 우선할 때

## 아트 보드 생성 프롬프트 요약

세 이미지 모두 내장 이미지 생성 도구로 제작했다. 공통 프롬프트는 “오리지널 코지 탑다운 픽셀 아트 동물 농장 마을, 3:2 전체 맵, 32px 타일 감각, 장애물과 통로가 분명한 게임플레이 가독성, UI·텍스트·워터마크·복제 캐릭터 금지”이며, 각 안에 중앙 광장형 / S자 개울 순환형 / 3단 계단식 지형을 각각 지정했다.

이미지는 분위기와 랜드마크 기준이며, 실제 플레이·충돌 검증은 같은 페이지의 `플레이 맵`에서 수행한다.
