음악 마을 맵 — 강변 레코드 거리

2안 구조를 그대로 두고 건물·조명·지면을 레퍼런스 기준으로 다시 그렸습니다. 지붕은 박공/맨사드/평지붕 세 종류, 창은 창틀·격자살·셔터 3겹, 1층은 줄무늬 어닝과 계단 현관, 옥상에는 안테나·굴뚝·옥상정원·방송탑이 올라갑니다. 가로등은 지면에 빛 웅덩이를 남기고, 광장 위로는 전구 줄이 늘어집니다. 클릭하면 조작이 시작되고 전체 보기(M)로 마을 전체를, 잠금 해제(L)로 다섯 거리를 모두 돌아볼 수 있습니다(현재 기본값: 해제 상태 — 실제 게임은 순차 언락).

2a 강변 레코드 거리 — 건물 리워크 2안 구조 유지 · 박공 지붕, 창틀·셔터, 줄무늬 어닝, 가로등 빛 웅덩이, 스트링 라이트
구현 연결점 music-village.js 가 맵 생성·충돌·드로잉을 전부 갖고 있고, DC는 입력/HUD/패널만 담당합니다. ZoneMap에 붙일 때 buildVillage('A'|'B') 의 결과를 그대로 쓰고, 소리 아이템 배열만 실제 SOUND_ITEMS.Music 로 교체하면 됩니다. 목업은 화면 확인용으로 블록당 8개만 스폰하지만, 실제 게임 기준(block_size=15)으로 올려도 배치 로직은 그대로 동작합니다.
충돌 모델 발밑 20×14px 히트박스, 축 분리 이동(moveWithCollision)으로 벽을 따라 미끄러집니다. 건물·소품·물·맵 테두리가 colliders 배열로 나오고, 디버그 프롭 showColliders 로 박스를 볼 수 있습니다.
전사 흐름 아이템 44px 이내 → SPACE → 패널에서 재생·의성어(80자)·자신감(1~5) → 제출 시 onSubmit({sound_id, zone, sub_category, expression_text, confidence}) 콜백. 기존 AnnotationPanel/Supabase 저장에 그대로 연결하면 됩니다.
